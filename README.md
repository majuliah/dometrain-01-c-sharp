# Getting Started: C#

> **Course:** Dometrain | Getting Started: C#
> `Getting Started` · `From Zero To Hero` ·

This course provides a foundational look at **C#**, a strongly-typed programming language. It is designed to help learners understand the core concepts required to build programs, starting with how data is managed.

---

## Key Topics

### 01 · Understanding Variables

Learn what variables are, why they are used to store state, and how they allow programs to work with information.

### 02 · Value Types

Explore essential data types including:

* **Integers** — For numeric values without decimal places.
* **Floating point/Doubles** — For numbers requiring decimal precision.
* **Booleans** — For simple true/false or on/off tracking.
* **Date and Time** — How to work with temporal data.

### 03 · Strong Typing

Understand the design philosophy of C# as a strongly-typed language, why it prevents the fluid mixing of different data types, and how this improves code clarity and maintainability.

### 04 · Practical Application

Discover how to effectively work with and convert between these different types within your C# code.
